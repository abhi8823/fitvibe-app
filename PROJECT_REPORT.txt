1. APPLICATION OVERVIEW & TECH STACK
======================================================================
FitVibe is a full-stack, AI-native web application designed to democratize fitness coaching. It provides users with customized training and nutritional plans, combined with a continuous conversational AI coach.

Tech Stack Details:
- Frontend: React + Vite SPA. Crafted using semantic HTML and custom, premium Vanilla CSS variables, glassmorphic layouts, and micro-animations to satisfy high visual excellence standards.
- Backend: Python FastAPI. Lightweight, asynchronous web server providing streaming endpoints (StreamingResponse) to deliver real-time AI responses.
- LLM Integration: Google Gemini API (gemini-3.5-flash) via the google-genai SDK.
- Containerization: Multi-stage Dockerfile compiling React static assets in Node and serving them via the FastAPI server, eliminating CORS and reducing cloud hosting costs to a single container.
- AWS Target Infrastructure: AWS App Runner (for instant container deployment) or AWS Elastic Beanstalk, using AWS System Manager Parameter Store for secure API key injection.

2. PROMPT ENGINEERING & PROMPTING STRATEGY
======================================================================
To achieve high-quality, structured output without rambling, a systematic prompting strategy was employed:

Role-Based Framing:
The model is instructed to assume the identity of an elite wellness coach (FitVibe).

Markdown Output Structuring:
The system instructions enforce the use of clean markdown: bolding for crucial values (e.g., calories), list items for workouts, and markdown tables for calendars.

System Instructions Snippet:
"You are FitVibe, an elite, motivational, and highly knowledgeable AI Health, Nutrition, and Workout Coach.
Your goal is to help the user achieve their fitness targets with precise, actionable, and science-backed advice.
Maintain a supportive, energetic, and positive tone. Make your answers concise, structured, and easy to read
using markdown (bullet points, bold highlights, sub-headers). Avoid lengthy paragraphs."

Dynamic User Prompt Example (For Plan Generation):
"Generate a highly customized, 7-day fitness and nutrition blueprint for a user with the following profile:
- Age: 25
- Gender: Male
- Weight: 70 kg
- Height: 175 cm
- Fitness Goal: Weight Loss
- Dietary Pattern: Vegetarian
- Daily Activity Level: Active

Please provide:
1. A calculated Daily Caloric & Macronutrient Target (Protein, Carbs, Fats).
2. A customized 7-Day Workout Plan matching their goals."

5. CHALLENGES ENCOUNTERED & RESOLUTIONS
======================================================================
Challenge 1: PowerShell Execution Script Restriction
- Problem: Local machine blocked scaffolding Vite because PowerShell script execution was disabled (npx.ps1 cannot be loaded).
- Resolution: Executed commands via cmd /c shell wrappers which run standard command shells bypassing PowerShell policy checks.

Challenge 2: Streaming Protocol Overloads
- Problem: Parsing complex Server-Sent Events (SSE) data lines like "data: { ... }" in frontend JS sometimes resulted in boundary split errors when chunks arrived fragmented.
- Resolution: Configured the FastAPI backend to stream plain-text (text/plain) chunks directly. This allowed the React frontend to run a simple, robust stream reader that reads and appends chunks directly without complex parsing.

6. KEY LEARNINGS & REFLECTION
======================================================================
- Vibe Coding Efficiency: Combining automated scaffolding with AI-native coding assistants allows rapid creation of professional-grade applications.
- Single-Container Advantage: Packaging the frontend compilation inside Docker and hosting the static directory via FastAPI completely removes CORS config headaches and allows deploying to simple cloud platforms (like AWS App Runner) in under 5 minutes on a single port.
- UX of AI: Implementing streaming output instead of spinners makes applications feel instantaneous and drastically increases user satisfaction.
